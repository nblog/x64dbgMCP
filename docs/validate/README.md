# Validate — 闭环验收记录

本目录是追加式回溯日志：记录每次推进完成后的闭环验证，标注验收时间，用于回溯"验证到了哪一步、证据是什么"。

## 收录范围

每条验收记录必须带 ISO 8601 日期，写清三件事：

- 验证范围：验证了什么，在哪个部署物/目标进程上
- 结果：通过、失败或部分通过，以及明确的边界
- 回溯所需的最小证据：构建产物哈希、日志摘录、输出文件路径、时间戳等

## 边界

- 不把决策理由写进验收记录，决策走 [`../adr/`](../adr/)
- 不用验收记录替代 ADR，也不用其修订 [`../tools-spec.md`](../tools-spec.md) 契约
- 未完成闭环的验证不落盘；失败但已闭环定位的排查进 [`../notes/`](../notes/)
- 与 [`../implementation-status.md`](../implementation-status.md) 的分工：该文件是可整体改写的"当前状态快照"（活文档），本目录是不可回改的时间线证据；该文件的 Verification boundary 只保留当前有效状态

## 格式与追加规则

- 每条记录以 ISO 8601 日期（YYYY-MM-DD）标注，条目按时间顺序统一排列
- 只追加新条目，不回改历史条目
