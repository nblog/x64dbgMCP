# Notes — 闭环问题调查与踩坑记录

本目录是追加式回溯日志：只收录**已闭环**的问题调查与踩坑记录，用于事后回溯，不承载决策，也不承载稳定约束。

## 收录范围

每条记录写清四要素：现象、根因、结论、规避方式，并标注 ISO 8601 日期。

适合进入本目录的内容：

- 排查闭环后的故障/异常行为分析（含根因与规避方式）
- 实施过程中踩过的坑及已确定的结论

不适合进入本目录的内容：

- 未闭环的排查、实验或实现过程草稿（不写入 `docs/`，闭环后再落盘）
- 稳定约束（架构、配置、契约、运行）→ 上层设计文档
- 决策（背景、选择、后果）→ [`../adr/`](../adr/)
- 推进完成后的闭环验收 → [`../validate/`](../validate/)

## 格式与追加规则

- 每条记录以 ISO 8601 日期（YYYY-MM-DD）标注，条目按时间顺序统一排列
- 只追加新条目，不回改历史条目；发现历史结论有误时，追加更正条目并链接原文
